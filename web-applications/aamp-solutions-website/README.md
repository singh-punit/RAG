# AAMP Solutions Website

Professional website for AAMP Solutions Pty Ltd - a leading cloud data solutions provider specializing in Azure, Databricks, Synapse, Microsoft Fabric, and Snowflake.

## Versions

### ⚛️ React Version (`react-version/`)

Modern React.js implementation with component-based architecture.

**Features:**

- Component-based architecture
- React hooks for state management
- Modern development workflow
- Optimized performance

**Setup:**

```bash
cd react-version
npm install
npm start          # Development server
npm run build      # Production build
```

### 🌐 Vanilla Version (`vanilla-version/`)

Traditional HTML/CSS/JavaScript implementation.

**Files:**

- `index.html` - Main HTML structure
- `styles.css` - Styling and animations
- `script.js` - Interactive functionality

**Usage:**

```bash
cd vanilla-version
open index.html    # Or serve with any web server
```

### 📱 Quick Preview (`preview.html`)

Single-file version for immediate preview without any setup.

**Usage:**

```bash
open preview.html  # No dependencies required!
```

## Deployment

### Static Hosting

Deploy any version to:

- Netlify
- Vercel
- GitHub Pages
- Azure Static Web Apps

### React Deployment

```bash
cd react-version
npm run build
# Deploy the 'build' folder
```

### Vanilla Deployment

Simply upload the files in `vanilla-version/` to any web server.
