# Utilities

Collection of utility scripts and tools for various tasks.

## 🐍 Python Scripts (`python-scripts/`)

### Letter Counter (`letter-counter/`)

- **Purpose**: Count letters in text strings
- **Type**: Utility script with unit tests
- **Use case**: Text processing, validation, analysis

### Loan EMI Calculator (`loan-emi-calculator/`)

- **Purpose**: Calculate loan EMI with detailed breakdown
- **Type**: Financial utility
- **Use case**: Loan planning, financial calculations

## Usage

Each utility is self-contained and can be run independently:

```bash
cd utilities/python-scripts/[utility-name]
python3 [script-name].py
```

## Characteristics

- **Focused**: Each utility solves a specific problem
- **Reusable**: Can be integrated into larger applications
- **Tested**: Include unit tests where applicable
- **Documented**: Clear usage instructions and examples
