# Development Repository

A well-organized collection of development projects, utilities, learning examples, and applications.

## 📁 Repository Structure

### 🛠 Utilities (`utilities/`)

**Purpose**: Focused tools and scripts for specific tasks

- **`python-scripts/`** - Utility scripts for text processing, calculations, etc.
  - Letter counter with unit tests
  - Loan EMI calculator with financial breakdown

### 📚 Learning Examples (`learning-examples/`)

**Purpose**: Educational code for learning programming concepts

- **`python-basics/`** - Fundamental Python concepts and syntax
- **`flask-minimal-app/`** - Introduction to web development with Flask

### 🚀 Projects (`projects/`)

**Purpose**: Complete applications demonstrating advanced concepts

- **`python-applications/`** - Full-featured Python applications
  - Magic number generator with complex algorithms

### 🌐 Web Applications (`web-applications/`)

**Purpose**: Production-ready web applications and websites

- **`aamp-solutions-website/`** - Professional business website (React + Vanilla versions)

### 🔌 MCP Servers (`mcp-servers/`)

**Purpose**: Model Context Protocol servers for AI tool integration

- **`text-processing-server/`** - Text utilities and processing tools
- **`azure-functions-server/`** - Serverless Azure Functions implementation

### ☁️ Azure Deployment (`azure-deployment/`)

**Purpose**: Cloud deployment configurations and documentation

- Deployment scripts, configurations, and best practices

## 🚀 Getting Started

1. **Choose your path**:

   - Learning? → `learning-examples/`
   - Need a utility? → `utilities/`
   - Want to see projects? → `projects/` or `web-applications/`

2. **Navigate to the specific folder**
3. **Read the local README** for detailed instructions
4. **Follow the setup and usage guide**

## 📝 Organization Philosophy

- **`utilities/`** - Single-purpose, reusable tools
- **`learning-examples/`** - Educational, simple, well-commented
- **`projects/`** - Complex, feature-rich applications
- **`web-applications/`** - Production-ready web solutions
- **`mcp-servers/`** - Specialized AI integration tools
- **`azure-deployment/`** - Cloud infrastructure and deployment

This structure makes it easy to find what you need and understand the complexity level of each component.
