# Flask Minimal App

A simple "Hello World" Flask web application demonstrating the basics of Flask framework.

## Files

- `flask-minimal-app.py` - Minimal Flask application

## Features

- Basic Flask route handling
- Simple HTTP response
- Development server setup

## Usage

### Install Flask

```bash
pip install flask
```

### Run the application

```bash
cd flask-minimal-app
python3 flask-minimal-app.py
```

### Access the application

Open your browser and go to: `http://localhost:5000`

## What it does

- Creates a Flask web server
- Responds with "Hello, World!" on the root route (`/`)
- Demonstrates the minimal setup required for a Flask application
